## Known limits, stated plainly

- **Judge–human agreement (κ/α) is not yet measured.** The reliability evidence
  in hand is inter-panel calibration (r=0.894, n=139). The human study is
  pre-registered in `validation/` against a frozen sample manifest; the paper
  prints `(forthcoming)` rather than a placeholder number.
- **The fine-tune arm is scaffolded, not trained.** `finetune/` exports the SFT
  set and drives evaluation, but the training step is compute-gated and has not
  been run. No lift number is claimed from it.
- **Full trajectory JSONLs are distributed out-of-band** (557 MB uncompressed,
  144 MB gzipped), with
  SHA-256 checksums committed here so any download verifies byte-for-byte. See
  `DATA.md`. Consequence: `verify_stats.py` FULL MODE — the numeric recompute of
  every headline statistic — is reproducible by anyone who requests the dataset,
  but not by a clone of this repo alone. A clone gets PREVIEW MODE
  (provenance / roster / checksum / lineage invariants) plus every executable
  gate above. FULL MODE is not hypothetical — it was run for this release
  (row 15) and the committed numbers came back key-for-key identical.
- **Three numbers are not reproducible even in FULL MODE.** `resLatencyPfifty`,
  `resLatencyPninety` and `resReliability` derive from a provider telemetry
  export (1.06 GB, sha256 `43ae1dbf…`) that is operational data and is not
  distributed. `paper-stats.lineage.sources` names it as a second input and says
  so; the other thirteen macros trace to the graded rollouts alone.
- **Every released row records `provenance.git.dirty = true`.** The canonical-135
  rollouts were generated inside the private development repo while that tree had
  uncommitted changes, so the recorded `git.sha` names the checkout each run
  started from, not the exact code bytes that produced the row. Pinned instead:
  `taskChecksum` (sha256 of the canonical scenario JSON), the frozen buyer-sim
  version, the seed, and the released rows' own digests. Not retroactively
  fixable for this freeze; disclosed rather than papered over. Going forward it
  cannot recur silently: `env rollout` and `env dataset` now refuse to emit from
  a dirty tree — or from a tree whose state cannot be determined at all (row 17)
  — and the only way past the gate announces itself.
